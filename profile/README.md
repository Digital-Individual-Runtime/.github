# Digital Individual Runtime

Digital Individual Runtime (DIR) is a modular foundation for building persistent digital individuals.

DIR provides reusable components for perception, cognition, memory, learning, agency, communication, and interaction with external environments. Its purpose is to support systems that maintain continuity over time, develop through experience, and operate across different applications, devices, and embodiments.

## Principles

- **Individual continuity** — identity, memory, relationships, and experience belong to the individual rather than to a particular model or provider.
- **Modular architecture** — capabilities are separated into focused runtimes and plugins that can evolve independently.
- **Model independence** — language models, local inference engines, and external providers remain replaceable.
- **Concurrent operation** — perception, reasoning, communication, and action can progress without forcing the entire system into a single sequential loop.
- **Portable integration** — DIR is designed for use in assistants, applications, games, robotics, simulations, and other interactive systems.
- **Observable behaviour** — important decisions and actions should remain traceable, testable, and explainable.

## Ecosystem

The organization hosts the core runtime and independent components for areas such as audio, vision, language, voice, agents, Web interaction, observability, and sandboxed execution.

Each repository has a focused responsibility and can be used independently where appropriate. Applications built with DIR remain separate products and do not define the runtime itself.

## Status

DIR is under active development. Its repositories are currently private while the architecture, interfaces, documentation, and release process are being consolidated.
